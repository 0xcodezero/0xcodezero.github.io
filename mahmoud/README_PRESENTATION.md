# TAME Technical Presentation

## Professional Web-Based Presentation on Transcatheter Arterial Micro-Embolization

This is a comprehensive, expert-level technical presentation on TAME (Transcatheter Arterial Micro-Embolization) designed for scientific conferences and interventional radiology specialists.

## How to Use

### Opening the Presentation

1. **Desktop/Laptop:**
   - Double-click `presentation.html`
   - Opens in your default web browser
   - Works offline - no internet connection required

2. **Alternative Method:**
   - Right-click `presentation.html`
   - Select "Open With" → Choose your preferred browser (Chrome, Firefox, Safari, Edge)

### Navigation Controls

#### Mouse/Touchpad
- **Next Slide:** Click "Next ▶" button
- **Previous Slide:** Click "◀ Previous" button
- **Jump to Slide:** Click "☰ Menu" to see all sections
- **Fullscreen:** Click "⛶ Fullscreen" button

#### Keyboard Shortcuts
- **→ or Space or Page Down:** Next slide
- **← or Page Up:** Previous slide
- **Home:** First slide
- **End:** Last slide
- **Esc:** Close menu or exit fullscreen

#### Touch Devices
- **Swipe Left:** Next slide
- **Swipe Right:** Previous slide

## Troubleshooting

### Presentation Won't Open
- Ensure file extension is `.html` (not `.txt`)
- Try different browser

- Refresh the page (F5)
- Clear browser cache
- Ensure JavaScript is enabled

- Use modern browser (update if needed)
- Check display resolution
- Try fullscreen mode

- Select "Print All Pages"
- Choose landscape orientation for better readability
